# 影像文书 — 高保真交互原型

按已选第 3 张视觉稿制作的本地 Vue / Yiitap 原型。

## 报告演示实现说明

面向 Vue 3 初学者的 [报告演示页面功能与实现指南](docs/report-demo-guide.md) 按当前代码讲解组件、数据流、Yiitap / Tiptap / ProseMirror API、引用、分栏、关键影像、拖动与打印。当前报告演示的功能边界以该指南为准；下方部分早期原型说明尚保留历史行为。

## 已实现

- A/B 医院独立配置（表头 6 / 5 个字段，表尾 3 / 2 个字段）。
- Yiitap 自定义 reportGrid / reportField 节点，预设列数、字段拖动、跨列、列宽、加粗、对齐与边框。
- 字段标签编辑、后台数据路径绑定、占位符 / 模拟数据实时预览。
- SQLite 保存模板 JSON、映射及正文，保存后刷新或重启恢复。
- 医生正文使用 Yiitap 自由编辑，表头表尾只读；已有报告保存模板与业务数据快照。
- 未保存切换提示、固定字段误删保护、保存期间编辑保护、版本冲突检查。
- 模板 JSON 查看、整页放大预览、窄屏布局。
- 报告页左侧提供当前患者、既往病历、常用模板。历史检查支持摘要展开及只读详情；模板支持搜索、部位筛选、预览及插入正文。

## 本地运行

Node.js 24+（使用 node:sqlite）、pnpm。

```sh
pnpm install
pnpm dev --host 127.0.0.1 --port 4173 --strictPort
```

当前电脑也可运行 `./start-local.sh`，使用 Codex 捆绑的运行时。服务仅监听本机。

- 浏览器： http://127.0.0.1:4173/
- 数据库： `data/reports.sqlite`（首次启动创建，后续启动不重置）
- 所有数据均为虚构模拟数据，没有真实医院接口、患者信息或 AI 诊断。
- 测试： `pnpm test`
- 构建： `pnpm build`

## 原型边界

这是一套本机演示，不包含登录、权限认证、影像查看、打印分页、PDF 导出、正式模板库管理或生产部署。

常用模板为内置模拟描述，插入到当前选区所在段落之后，保留已有文字及选区内容，支持单步撤销；插入后需要医生检查、编辑并点击“保存报告”。历史检查只关联当前医院的指定模拟患者，陈小宇病例用于演示无历史记录。历史记录和描述模板并非真实医院接口数据。

前端采用 Product Design 的 starter，保留其 Sites 打包文件；但 SQLite API 是本地 Vite 插件，**不能仅上传静态构建就获得完整服务**。云端部署需另行适配 API 与数据库，当前没有发布到公网。

字段在文档流内排列，支持拖动与跨列，不支持任意绝对坐标定位。标签与字段绑定不会因拖动而变化。

每个模拟病例维护一份报告，已有报告使用保存时的模板快照。演示新模板时可使用另一个尚未保存的病例。

## 目录

- `src/`：界面、绑定模型、Yiitap 扩展。
- `server/`：本地 API 与 SQLite 持久化。
- `tests/`：字段、Schema、保存竞态与数据库测试。
- `assets/design-reference.png`：已选视觉稿。
- `qa/` 与 `design-qa.md`：浏览器证据与视觉检查。

依赖均固定在 pnpm-lock.yaml 中。Yiitap 包含较多编辑扩展，当前构建会提示部分 JS chunk 较大；原型未进行生产级首屏体积优化。

### 自由配置字段

表头、表尾的初始字段均可新增、删除、改名、排序与调整样式，也允许删空后保存。新增字段默认未绑定，在“数据来源”中选择后台字段即可绑定，选择“未绑定（解除绑定）”可解除。删除字段时同步删除绑定；当前编辑会话内撤销删除会恢复原绑定。医院名称可在表头配置中编辑，留空隐藏，旧模板默认使用所属医院名称。各医院独立保存，已有报告快照保留原配置。

## 自由模板菜单（2026-11-02）

本地入口：`http://127.0.0.1:4173/#native-templates`。原「模板配置」和「报告演示」继续保留。

- 表头、表尾采用 Yiitap 富文档，可自由写文字、格式化、插入表格和两栏布局。输入 `/` 或 `／` 搜索插入基础内容与业务字段。
- 已有默认字段首次从当前医院原模板复制，之后独立保存至 `data/native-templates.sqlite`；A/B 医院分别保存。旧模板和已存报告不受新菜单保存影响。
- 拖动块左侧手柄调整顺序；字段占位符可直接拖动。移动内容不修改绑定，撤销拖动不撤销此前输入。
- 「字段与绑定」用于自定义字段、调整或解除数据来源；添加定义后需显式插入到文档。默认字段无需重复配置。
- 模拟数据开关、缩小/放大预览、未保存离开保护、保存版本冲突提示均已接入。

当前范围是独立模板编辑和实时预览，新格式尚未接入旧「报告演示」生成流程；预览不提供正式打印分页/PDF。首次复制保留字段顺序、跨度、名称和绑定，但不会逐像素复制旧网格边框/列宽。

实现说明：复用 Yiitap 的 OSlash/OSlashZh 生命周期、表格/分栏和编辑器 schema；业务中文名称使用专用菜单渲染适配。块手柄复用 Yiitap UI，通过 ProseMirror 单次事务适配 WebKit 拖拽；字段仍使用原生文档拖拽。没有增加依赖。

验证记录见 `../design-qa.md`。39 项测试通过，生产构建成功；构建仍提示部分 Yiitap 依赖块超过 500 kB。
