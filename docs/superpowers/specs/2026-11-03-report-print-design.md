# 报告多页打印（已确认）

报告演示增加打印入口，先展示 A4 纵向分页预览，再调用系统打印（可保存 PDF）。使用当前编辑器内容，包括未保存修改；打印不触发保存。每页重复医院名称、报告标题、模板表头患者信息，并显示第 X 页 / 共 Y 页。模板签署字段仅末页显示。

文本自动续页，标题跟随正文；表格按行分页并重复表头，超高行可拆分；图片行尽量整体换页，图片等比例缩放；文字分栏续页保留各栏关系。不得裁切、漏印或打印编辑手柄、侧栏、空图片提示。

采用浏览器实际字体/图片完成加载后的尺寸测量，生成固定 A4 页。打印和预览共用分页结果。与单纯 CSS 打印相比可预览页数且分页一致；无需增加 PDF 服务或改动正文持久化格式。

默认页边距上下 14mm、左右 16mm。页码位于底部；签署字段作为末尾不可拆分块，尽可能与最后一段同页。图片加载失败或页头/签署区域无法放入 A4 时给出错误，禁止不完整打印。系统打印以 A4、100% 缩放为目标；打印对话框由用户选择打印机或保存 PDF。
